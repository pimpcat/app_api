# Logos institucionales

Los archivos listados en `../branding.json` → clave `logos` deben vivir aquí.

Config actual del plugin:

| Archivo | Institución |
|---------|-------------|
| `seplader.png` | SEPLADER |
| `cesieg.png` | CESIEG Guerrero |

Para cambiar logos o la línea de marca, edita `assets/branding.json` (o apunta
`CARTOGRAPHY_BRANDING_FILE` a otro JSON). No hardcodees nombres en el código.

Preferible: PNG con fondo transparente. Versiones con fondo negro se ven como
bloque oscuro sobre la tira/franja clara del PDF.
